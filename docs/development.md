# Разработка

`AGENTS.md` содержит устойчивые ограничения и ссылки на тематические документы. Отдельные навыки пока не добавлены: повторяемого узкого процесса, требующего дополнительного workflow, нет. Это применение [рекомендаций по навыкам и инструкциям](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra): краткий контекст, точные критерии завершения, чтение документов по необходимости.

Ветки: feature/..., fix/..., docs/... — без обозначений ИИ. Локальные тесты используют одноразовые fixtures, не production; их можно выполнять и исправлять без повторных согласований. Документационная правка не требует полного интеграционного прогона.

`make check`: GoDoc, gofmt, go vet, unit + race, суммарное покрытие >=70%. `-coverpkg=./...` включает весь модуль, в том числе cmd и persistence. Crypto тестирует AEAD; API — права; client — конфликты и retries; CLI — сценарии; store — транзакции с pgxmock.

`make integration` добавляет тесты с тегом integration на реальной PostgreSQL из GOPHKEEPER_TEST_DATABASE_URL. Только одноразовая база: создаются уникальные аккаунты, произвольные существующие таблицы не очищаются. CI использует отдельный service container.

GoDoc-check проверяет наличие комментария, полноту оценивает ревью. При изменении формата обновляйте модель, тесты, примеры, OpenAPI и описание безопасности. При обновлении зависимостей полезен `go run golang.org/x/vuln/cmd/govulncheck@latest ./...`.
