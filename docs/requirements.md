# Требования и приёмка

Источник — предоставленное пользователем ТЗ «Менеджер паролей GophKeeper».

| Требование | Реализация | Проверка |
|---|---|---|
| Регистрация, вход, авторизация | /v1/register, /v1/login, сессии, namespace владельца | API unit + PostgreSQL integration |
| Хранение и выдача данных | AES-GCM на клиенте, PostgreSQL | crypto tests, CLI roundtrip |
| Несколько клиентов | Снимок, версии, очередь, tombstones | TwoClientsConflictAndDeletion |
| Четыре типа | credentials, text, binary, card | CLI Workflow |
| Произвольная метаинформация | metadata внутри шифротекста | CLI/client tests |
| Windows/Linux/macOS CLI | Чистый Go, amd64/arm64 | CI platforms, cross-build |
| Версия и дата | version/--version, ldflags | CLI tests, build |
| Unit coverage >=70% | make test, все пакеты ./... | Порог Makefile |
| GoDoc пакетов и экспортируемого API | Комментарии и тематические документы | check-docs.go и ревью |

Создание, изменение и удаление инициирует клиент, сервер применяет шифротекст. Регистрация: логин, пароль входа и отдельный клиентский пароль шифрования. Конфликты решаются явным выбором пользователя.

Дополнительно: офлайн-кэш, интеграционные тесты и OpenAPI. Необязательные OTP, TUI и бинарный протокол не входят в первую версию.

Готовность: успешные проверки, сборки, подтверждённые сценарии запуска и актуальная документация. Наличие CI-файла не доказывает прохождение удалённого CI; его результат проверяется отдельно.
