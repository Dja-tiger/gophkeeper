# Происхождение кода

Исходники написаны для данного ТЗ. Код из itallix/gophkeeper и andreevym/gophkeeper не копировался; эти репозитории использовались только для предварительного анализа подходов и рисков.

Зависимости go.mod/go.sum сохраняют собственные лицензии: pgx, golang.org/x/crypto, x/term, pgxmock (тесты) и транзитивные зависимости. При будущем заимствовании фрагментов сохраняйте лицензию, авторство и источник в этом файле.
